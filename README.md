# WorkFlow Smart

Build a modern, professional AI-powered workplace productivity assistant that integrates three connected features: (1) Meeting notes summarizer where users paste long notes and receive concise summary points, key discussion points, decisions, action items, deadlines, and task owners when identifiable. (2) AI task planner where users enter tasks or import action items from meeting analysis; AI organizes them, assigns high/medium/low priority based on urgency and importance, suggests deadlines, produces a structured daily or weekly work plan, and recommends time organization. (3) Smart email generator where users enter recipient, email purpose, key information, and desired tone to generate polished workplace emails. Ensure the features work as one unified assistant: meeting action items can flow into the planner, and tasks/meeting context can inform emails. Use a modern professional responsive UI with realistic demo data and clear navigation. Enable Lovable Cloud for saved user data and AI functionality.
